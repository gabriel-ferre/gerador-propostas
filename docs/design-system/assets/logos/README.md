# Logos

O logotipo da Retrieve é um **R com seta ascendente integrada** (retomada / crescimento) + o wordmark "Retrieve" em Apfel Grotezk. Use sempre os arquivos abaixo — nunca redesenhe, recolora ou distorça o símbolo.

| Arquivo | Tinta | Fundo | Quando usar |
|---|---|---|---|
| `retrieve-logo-primary.png` | símbolo `brand-red` + wordmark `brand-black` | transparente | Padrão sobre `white` e superfícies claras. |
| `retrieve-logo-white.png` | símbolo `brand-red` + wordmark `white` | transparente | Sobre `ink-950`, `ink-900`, `deck-navy`, `cover-navy`. |
| `retrieve-logo-red.png` | símbolo `brand-red` | transparente | Símbolo isolado: avatar, favicon, marca d'água, bordado. |
| `retrieve-logo-horizontal.png` | símbolo `brand-red` + wordmark branco | transparente | Cabeçalhos e rodapés escuros, cabeçalho de slides do Plano de Retomada. Não use sobre fundo claro (o wordmark some). |
| `retrieve-simbolo-vermelho-fundo-preto.png` | `brand-red` | preto | Avatar de redes sociais / capa preta. |
| `retrieve-capa-padrao.png` | `brand-red` + © | degradê preto → `deck-navy` | Capa padrão (avatar, thumbnails, capas de material). |
| `retrieve-simbolo-preto-fundo-branco.png` | `brand-black` | branco | Versão monocromática: documentos, carimbos, impressão em uma cor. |
| `retrieve-simbolo-azul-fundo-preto.png` | azul claro (~#3f88fa, fora da paleta oficial) | preto | Variação de campanha. Não é cor da marca — use só onde já foi aprovada. |

- O © acompanha o símbolo em capas e assinaturas institucionais (como no manual).
- O manual aplica o logo inteiro em branco sobre `cover-red` e `cover-navy`. Esse arquivo (símbolo branco) não está no sistema: peça a versão vetorial ao design antes de compor sobre vermelho.
